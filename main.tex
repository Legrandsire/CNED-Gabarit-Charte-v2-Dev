% Balisage automatique par le noyau LaTeX (chantier refonte des titres) :
% phase-II = activation du tagging + balisage des paragraphes (remplace le
% chargement manuel de tagpdf avec activate-all,paratagging=true) ;
% sec = balisage automatique du sectionnement (\part...\subparagraph).
% Les autres modules (block, graphic, float, table, math) seront actives
% un par un en phase 3, chaque cran mesure par PAC.
%
% Aiguillage selon la generation du noyau :
% - noyau <= 2025-06 (Overleaf, TeX Live 2025) : cles testphase granulaires,
%   activation ciblee phase-II + sec, conforme au plan du chantier ;
% - noyau >= 2025-11 (MiKTeX local) : \DocumentMetadata y charge
%   inconditionnellement latex-lab, dont les paquets locaux (2026-04)
%   referencent des macros du noyau 2026 absentes du format 2025-11 —
%   notes de bas de page et sectionnement natif partent en boucle
%   (diagnostic par bissection, 2026-07-25 ; titlesec masquait le
%   probleme). On n'appelle donc PAS \DocumentMetadata : compilation
%   entierement classique, sans balisage — la verification locale est
%   purement visuelle, comme documente dans chantier_refonte_titres.md.
%   Seules les commandes tagpdf du pied de page recoivent des no-ops.
%   A reevaluer quand Overleaf passera sur un noyau recent (le PAC d'un
%   jalon montrerait alors ~0 balise) ou quand MiKTeX sera realigne.
